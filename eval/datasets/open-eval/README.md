# Датасет `open-eval`: запити й розмітка (R-02)

Запити й розмітка для підкорпусу `open-eval` (902 документи з відкритого корпусу R-01; `manifest-eval.jsonl` лежить у `eval/datasets/open/`).
Сам корпус (`corpus/`) у Git не потрапляє; для `localmind eval --dataset <тека>` потрібна тека з `corpus/`, `queries.jsonl` і `qrels.jsonl`.
Протокол, інструкція оцінювання й інструменти — [eval/datasets/open/labeling/README.md](../open/labeling/README.md).

## Склад

- **90 запитів**: по 30 `exact`, `paraphrase`, `crossLingual`. Мови запитів: uk 40, en 38, de 4, fr 4, pl 4; російської немає.
- **qrels.jsonl**: 274 пари; 237 з оцінкою 3 і 37 з оцінкою 1 (у середньому ≈ 3 релевантні документи на запит).
  Оцінки 3 — це насамперед документ-джерело й версії тієї самої статті іншими мовами (210 пар «авто»), решта — документи, оцінені за фрагментом.
- **labeling/judgments.jsonl**: усі 680 оцінок за пулом (top-10 з keyword, semantic і hybrid), включно з нулями: 0 — 616, 1 — 37, 3 — 27.
  Кожен запис має поля `by` і `how`. Оцінки поставив агент (Claude) за інструкцією v1; кандидату без явної оцінки поставлено 0 після перегляду фрагмента й заголовка.
- **labeling/sample.jsonl**: документ-джерело, тип і мови кожного запиту (мета).
- **labeling/sample-for-humans.md**: 30 пар для перевірки командою (порожня колонка «згоден/ні»).

## Як створено

1. Стратифікована вибірка 90 документів-джерел з маніфесту (`label.py sample`, зерно 1).
2. Запити написано **від документа**, без звернення до пошуку LocalMind; `label.py check-queries` підтвердив, що в `paraphrase` немає жодного
   значущого слова чи основи з документа, у `exact` усі слова є в тексті, мова запиту відповідає типу, російської немає.
3. Корпус проіндексовано моделлю `multilingual-e5-small`, для кожного запиту взято top-10 із трьох режимів і об'єднано (`label.py pool`, `candidates`).
4. Кандидатів оцінено за фрагментом і заголовком; `build` записав `queries.jsonl` і `qrels.jsonl` (нулі в qrels не пишуться).

## Обмеження, про які треба пам'ятати

- **Оцінки поставив один агент.** Захист — вибіркова перевірка людьми (`sample-for-humans.md`) і запис усіх оцінок з нулями; до перевірки команди
  узгодженість із людьми невідома.
- **Оцінки 2 не використано**: за правилом «сумнів → нижча» агент ставив 1 або 3. Для nDCG це означає майже бінарну розмітку з вагою 3.
- **Пул обмежений трьома режимами системи.** Документи, яких жоден режим не знайшов, не оцінювалися (відомий недолік пулінгу): якщо серед них були
  релевантні, recall усіх режимів завищений.
- **Документи-джерела й переклади отримують 3 автоматично.** Для `crossLingual` це надійно (версії тієї самої статті), а для `exact` і `paraphrase`
  документ-джерело — єдиний гарантовано релевантний.
- **Інша мова тієї самої теми** (стаття про те саме іншою мовою, що не потрапила в групу) оцінювалася як 3 за правилом «переклад оцінюється так само, як оригінал».
- **У базі розмітки не було одного порожнього фрагмента** з PDF `київ-5165eb.pdf` (його вилучено з тимчасової бази пулінгу; корпус не змінено): він ламав читання результатів.
