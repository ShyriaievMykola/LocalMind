# Відкритий багатомовний корпус нотаток (R-01)

Реальні відкриті тексти для досліджень E1–E4 (чанкінг, моделі embeddings, HNSW, cross-lingual), замість синтетики:
різні мови, жанри, довжини й формати файлів. Корпус **не лежить у Git** (розмір і ліцензії): у репозиторії скрипт
[`build_corpus.py`](build_corpus.py), маніфест [`manifest.jsonl`](manifest.jsonl) і цей README. Теки `corpus/`,
`.cache/` і `.venv/` у `.gitignore`.

Російської в корпусі немає: жодне джерело `ru.*` не береться, а кожен документ проходить перевірку мови (див. нижче).
Запитів (`queries.jsonl`) і розмітки (`qrels.jsonl`) поки немає — це окрема задача; корпус вже придатний для
`localmind index` і замірів швидкості/розміру.

## Формат

```
corpus/<джерело>/<мова>/<назва>-<хеш>.<md|txt|docx|pdf>
```

- `.md` і `.txt` — основна частина; `.docx` (python-docx) і `.pdf` (reportlab, шрифт з кирилицею) ≈ 8 %, згенеровані з
  тих самих текстів, щоб перевірити парсери індексатора (LocalMind індексує саме `.md`, `.txt`, `.docx`, `.pdf`).
- Довжини: від нотатки на абзац (вступи статей, рецепти) до розділу книги чи повного путівника; верхня межа — 40 000 символів
  для md/txt, 20 000 для docx і 12 000 для pdf (довші тексти обрізаються по межі абзацу).
- У `.md` перший рядок — `# Заголовок`, далі текст із markdown-заголовками розділів; у `.txt` розмітки немає.

### manifest.jsonl

Один JSON на рядок, відсортовано за `path`:

| Поле | Значення |
|---|---|
| `path` | шлях відносно `corpus/` (`/` як роздільник) — саме так його приймає `qrels.jsonl` |
| `lang` | `uk`, `en`, `de`, `pl`, `fr`, `es`, `it` |
| `source` | `wikipedia`, `wikivoyage`, `cookbook`, `wikisource`, `gutenberg`, `stackexchange` |
| `url` | сторінка першоджерела |
| `license` | ліцензія тексту |
| `topic` | тема: programming, it, science, medicine, history, geography, travel, cooking, sports, finance, law, art, nature, literature, languages |
| `sha256` | хеш файла (перевірка цілісності) |
| `group` | ключ «та сама тема різними мовами»: англійська назва статті/путівника; для книг — `pg<номер>`, для Q&A — `se<id>` |
| `title`, `format`, `chars`, `bytes`, `authors`, `retrieved` | заголовок, формат, розмір, автори (Q&A, книги), дата завантаження |

Документи однієї статті різними мовами (`group` однаковий) — це готова основа для cross-lingual запитів і розмітки.

## Як зібрати

```bash
cd eval/datasets/open
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt     # Linux/macOS: .venv/bin/pip
.venv/Scripts/python build_corpus.py              # корпус у corpus/, маніфест у manifest.jsonl
```

Корисні ключі: `--sources wikipedia,gutenberg` (лише ці джерела), `--scale 0.05` (швидка перевірка на 5 % обсягу),
`--out`, `--cache`, `--pdf-font` (TTF з кирилицею для PDF; за замовчуванням шукається DejaVu Sans, Liberation чи Arial,
а без шрифта PDF замінюються на DOCX). Тести: `python -m unittest discover -s . -p "test_*.py"`.

Скрипт користується лише офіційними API й нічого з завантаженого не виконує: MediaWiki API (`*.wikipedia.org`,
`*.wikivoyage.org`, `en.wikibooks.org`, `uk.wikisource.org`), Stack Exchange API без ключа і gutenberg.org (каталог
`pg_catalog.csv` та тексти). User-Agent нейтральний — `LocalMind-corpus/1.0 (student research project)`. Запити йдуть
послідовно, відповіді кешуються в `.cache/`, тож повторний запуск майже не торкається мережі й дає той самий корпус.

**Час збирання.** Вікімедія для клієнта без контакту в User-Agent пускає ≈10 запитів на хвилину на всі свої сайти
разом (виміряно: після десяти — `429`, через ≈60 с знов десять). Тому скрипт робить пакетні запити (wikitext по 8 статей,
extracts по 20, міжмовні посилання по 50 назв) і тримає паузу 6,5 с (`--wiki-pause`); вікі-частина — це ≈600 запитів,
тобто близько 1,5 години. Gutenberg і Stack Exchange мають окремі ліміти й збираються за пару хвилин. Повний текст із
вікірозмітки очищається `mwparserfromhell` (шаблони, виноски, таблиці, файли, категорії та службові розділи
«Примітки», «Посилання», «See also» тощо прибираються).

Вибірка детермінована: теми й вихідні статті задано в `TOPIC_SEEDS` (англійські назви; береться ті, що мають
українську версію), решта вибору мов, режиму «вступ чи повний текст» і книг Gutenberg — за хешем назви й `--seed`.
Зміст самих сторінок з часом змінюється, тому пересборка через місяці дасть трохи інші тексти; точні хеші збірки лежать у
`manifest.jsonl`.

## Перевірка мови: жодної російської

Для кожного документа (див. `language_ok` у скрипті):

1. літери `ы э ъ ё` у кириличному тексті — не більше 0,5 % кириличних символів (в українській їх немає);
2. детектор `langdetect` (з фіксованим seed) не повертає `ru`;
3. для текстів від 600 символів мова за детектором збігається з очікуваною; Q&A з `ukrainian.stackexchange` (англійські
   питання з українськими прикладами) отримує `uk` чи `en` за детектором.

Блоки коду перед визначенням мови виключаються. Документи, що не пройшли перевірку, не потрапляють ні у файли, ні в маніфест.
Крім того, у корпус не потрапляють файли, які антивірус Windows блокує як підозрілі (приклади експлойтів у Q&A про безпеку).
